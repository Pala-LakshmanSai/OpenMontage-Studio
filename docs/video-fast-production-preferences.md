## Production steps

Across all styles, apply [minimum shot duration](minimum-shot-duration-preferences.md):
no one-second flash clips; ordinary actual shots last at least 2 seconds unless
the owner explicitly requests shorter cuts. Generated chunk length is not shot
length. Use actual returned boundaries when splitting multi-scene assets and run
one cached local output check, without paid assessment or repeated audits.

1. Read the relevant saved brief and style once. Set a concise story/sequence plan, identity/voice references, required continuity and actual budget. Reuse settled choices; do not reopen approval or setup questions already authorized. Give takes an explicit story order and canonical scene ID before generation. Assembly follows that order; never infer chronology from provider filenames, day labels or job aliases.
2. Freeze each sequence's direction once. Generate independent sequences concurrently within provider and budget limits. Use longer useful passages and simple achievable actions. Assemble selected footage while later sequences generate. Write each completed asset path, usable range and scene ID to its branch selections file immediately, before narrative reports; the coordinator consumes these incrementally without waiting for the whole branch or another review handoff. Keep render/conform caches so unchanged scenes are not rebuilt.
3. Use a quick glance for obvious defects when a dependent shot needs its predecessor's state. Extract its actual outgoing frame unchanged where supported. Do not require full playback, transcription, contact sheets, paid model assessment or a separate review report for every clip before proceeding.
4. Accept minor texture, wrinkle, movement and incidental prop imperfections. Correct clear audience-visible problems: a changed character, major teleport/morph, unintelligible required speech, missing story outcome, broken sound or severe continuity failure. Prefer a sensible trim or motivated cut to a paid reroll. Do not retry just to polish a usable take.
5. Batch one short final check: playable file, requested approximate duration/resolution, picture fills frame, present and intelligible audio at sensible levels, essential scenes included, obvious identity/continuity errors and successful requested delivery/sharing. Sample key moments and transitions; full real-time viewing, frame-by-frame inspection, every-join review, per-shot ASR, duplicate independent audits and paid audiovisual scoring are not default requirements. Investigate further only for a concrete observed fault or an explicit request.
6. Deliver promptly. Keep lightweight receipts and existing automatic validation; do not build a new review framework, launch redundant tests or create extensive QA paperwork for an ordinary production.
